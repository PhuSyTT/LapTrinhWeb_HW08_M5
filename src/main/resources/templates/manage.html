Hướng Dẫn Truy Vấn GraphQL API Endpoints

Tất cả các truy vấn và mutation đều được gửi tới endpoint duy nhất: POST /graphql với header Content-Type: application/json.

1. Query Sản Phẩm Theo Giá Tăng Dần 
query {
  productsSortedByPrice(ascending: true) {
    productId
    productName
    unitPrice
    discount
    category {
      categoryName
    }
  }
}
2. Query Sản Phẩm Theo 1 Category 
query {
  productsByCategory(categoryId: 1) {
    productId
    productName
    unitPrice
    quantity
    images
  }
}
3. Phân Trang & Tìm Kiếm Product 
query {
  productsPage(page: 0, size: 5, name: "iPhone") {
    content {
      productId
      productName
      unitPrice
    }
    pageInfo {
      totalElements
      totalPages
      pageNumber
    }
  }
}
4. Mutation Thêm Sản Phẩm Mới 
mutation {
  createProduct(input: {
    productName: "Laptop Dell XPS 15"
    unitPrice: 45000000.0
    quantity: 15
    discount: 5.0
    categoryId: 2
  }) {
    productId
    productName
  }
}
