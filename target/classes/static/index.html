Tài Liệu RESTful API Endpoints

Các API được xây dựng theo chuẩn Spring Boot 3 và tài liệu hướng dẫn giảng dạy môn Lập trình Web.

Category RESTful APIs (/api/category)
  • GET/api/category Lấy tất cả danh mục
  • POST/api/category/getCategory Lấy chi tiết theo ID
  • POST/api/category/addCategory Thêm mới + Upload Icon
  • PUT/api/category/updateCategory Cập nhật + Upload Icon
  • DELETE/api/category/deleteCategory Xóa danh mục theo ID
Product RESTful APIs (/api/product)
  • GET/api/product Lấy tất cả sản phẩm
  • POST/api/product/getProduct Lấy chi tiết sản phẩm
  • POST/api/product/addProduct Thêm mới + Upload ảnh
  • PUT/api/product/updateProduct Cập nhật + Upload ảnh
  • DELETE/api/product/deleteProduct Xóa sản phẩm theo ID
